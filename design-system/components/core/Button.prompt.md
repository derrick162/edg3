Indigo→violet gradient action button with an ambient glow; use for the single primary action on a screen, with `secondary` and `subtle` for lower-priority actions.

```jsx
<Button variant="primary" size="lg">Meet your Chief of Staff →</Button>
<Button variant="secondary">Already a member</Button>
<Button variant="subtle">Skip for now</Button>
```

Variants: `primary` (gradient + glow shadow, lifts on hover), `secondary` (transparent with hairline border, indigo tint on hover), `subtle` (quiet faint text, for tertiary actions like "Sign out"). Sizes: `sm` / `md` / `lg`. Supports `fullWidth` and `disabled`. Arrow glyphs (→) are idiomatic in primary CTAs.
