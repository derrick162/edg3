The EDG3 wordmark in the signature ink→violet→indigo gradient. The brand has no icon mark — the gradient wordmark *is* the logo.

```jsx
<Logo size={24} />
<Logo size={32} eyebrow />           {/* with "ELITE DAILY GUIDANCE ENGINE" line */}
<Logo text="E" size={28} />          {/* compact single-letter mark for avatars */}
```

Always set on the dark canvas — the gradient is tuned for near-black. Use `eyebrow` on auth and marketing headers; omit it inside the app chrome.
